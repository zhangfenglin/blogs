# DeepSeek Harness 源码阅读 · 必看文档

整理 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 源码的目录地图与 `packages/` 分组，阅读时作跳转用。架构叙述与官方 doc 顺序见 [系列导读](./00-系列导读.md)；下文只标源码位置与阅读锚点。

## 核心概念

| 名词 | 读源码时 |
|------|----------|
| 插件树 | 一切皆插件；由 Profile 叠 Bundle patch 挂载（[`architecture.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/architecture.zh.md)） |
| `@deepseek-ai/dsh-*` | 业务包名；路径 `packages/<group>/<pkg>/` |
| Cordis | [`vendor/cordis/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/vendor/cordis)；语义 [`cordis-primer.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/cordis-primer.zh.md) |
| patch 叠加 | `dsh.profile.bundles` → profile `cordis.patch.yml` → `$DSH_HOME/cordis.patch.yml` → `--patch`；`dsh --profile web --dump-config` 看本机树 |

读 `packages/core/*` 时分清事件（矩阵 [`event-producer-consumer.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/event-producer-consumer.zh.md)）：

| 域 | 典型前缀 |
|----|----------|
| SessionEvent | `turn/*`、`step/*`、`user/message`、`assistant/*`、`tool/*` 等（[`known-event-types.ts`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/packages/core/session/src/known-event-types.ts)） |
| Agent 事件 | `agent/pre-step`、`agent/inbox/inserted`、`agent/status` 等 |
| 能力 hook | `fs/*`、`tools/*`、`session-telemetry/record` |

`agent/*` 前缀在 SessionEvent 与 Cordis 实时事件间会撞名（如实时 `agent/pre-step` vs 日志 `agent/inbox/spliced`）。

## 结构索引

路径相对于 [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) 仓库根目录（commit 等同 [系列导读](./00-系列导读.md) 资料基线）。

### 顶层目录

```text
deepseek-harness/
├── apps/              # CLI（cli/）与 Web 前端构建（web/）
├── packages/          # @deepseek-ai/dsh-* 业务包
├── vendor/            # 内嵌 Cordis 等
├── docs/              # 架构、子系统、cookbook
├── examples/          # runnable 演示与 cordis 组合（含 overlay patch）
├── python/            # Python SDK
├── native/            # Landlock 沙箱（landlock-run/）
├── scripts/           # CI、代码生成
└── website/           # VitePress 文档站
```

### `packages/` 分组

| 分组 | 代表路径 | 职责 |
|------|----------|------|
| 核心包 | `packages/core/*`、`llm/llm` | Agent 契约（`agent`）、默认 loop（`agent-loop`）、会话（`session`）、工具（`tools`）、提示词（`system-prompt`）、LLM seam（`llm`） |
| 启动与组合 | `boot/app-boot/`、`bundle/base/`、`bundle/web-app/`、`bundle/headless/` | Profile、`composeProfile`/`boot()`、各 profile 的 `cordis.patch.yml` 层 |
| 能力 seam | `fs/`、`shell/`、`subprocess/`、`sandbox/`、`subagent/`、`interaction/` | 可替换提供方（[`capability-seams.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/capability-seams.zh.md)） |
| 会话与 Web | `session/`、`host/`、`client/` | 持久化后端、API 网关、浏览器壳 |
| 集成 | `acp/`、`sdk/`、`api/`、`mcp/` | ACP、JSON-RPC SDK、Remote BFF、MCP 客户端 |

完整列表见 [`packages/README.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/packages/README.md)。

### 可运行示例

`examples/` 下 6 个子目录（[`examples/README.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/examples/README.zh.md)）；各目录自有 `cordis.yml` 或 `*.cordis.yml` 与 README。与 `packages/examples/`（demo bin，如 `acp-demo` 加载 `examples/acp-agent/cordis.yml`）不是同一层，亦不同于 `packages/bundle/` 的 profile 层。

| 路径 | 类型 | 说明 |
|------|------|------|
| [`headless-agent/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/headless-agent) | 叶节点 | headless 组合的测试/回放 `cordis.yml`；产品入口 `dsh --profile headless "task"` |
| [`acp-agent/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/acp-agent) | 叶节点 | ACP stdio 服务器；仓库根 `pnpm run demo:acp` |
| [`jsonrpc-agent/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/jsonrpc-agent) | 叶节点 | Python SDK JSON-RPC 无人值守组合；非 `dsh` CLI 入口 |
| [`web-cordis/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/web-cordis) | 叶节点 | `dsh-tool-cordis` 自引用演示；`pnpm run demo:cordis` |
| [`web-schedule/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/web-schedule) | overlay | Session 内定时提醒；`dsh web --patch examples/web-schedule/cordis.yml` |
| [`mcp-memory/`](https://github.com/deepseek-ai/deepseek-harness/tree/47f943859b/examples/mcp-memory) | overlay | 默认关闭的三份 MCP 记忆参考 patch（`memorix` / `mcp-reference-memory` / `engram`）；`dsh web --patch examples/mcp-memory/<file>.cordis.yml` |
