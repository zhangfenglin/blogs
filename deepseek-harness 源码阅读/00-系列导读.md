# DeepSeek Harness 源码阅读 · 系列导读

1. **[01-必看文档](./01-必看文档.md)** — 建立目录地图与阅读锚点。

   - [`cordis-primer.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/cordis-primer.zh.md)
   - [`agent-lifecycle.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/agent-lifecycle.zh.md)
   - [`tool-execution-pipeline.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/tool-execution-pipeline.zh.md)
   - [`event-producer-consumer.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/event-producer-consumer.zh.md)
   - [`capability-seams.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/capability-seams.zh.md)
3. **源码锚点** — 在 [01-必看文档](./01-必看文档.md) 查启动链与 `packages/` 分组，按需跳进对应路径。
4. **深度篇** — 从 `02` 起按上表顺序；每篇只走一条链路（turn/step、SessionEvent、waterfall 等概念在正文与 [`cordis-primer.zh.md`](https://github.com/deepseek-ai/deepseek-harness/blob/47f943859b/docs/cordis-primer.zh.md) 中随读随查）。
